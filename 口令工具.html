5发布后会发生什么

  1. 本地使用者：文件已自动写回工具文件夹，重新打开 index.html，旧口令被拒绝、新口令能进，即成功。
  2. Cloudflare 使用者：双击生成的 一键发布.bat → 看到「✓ 发布成功」→ 用无痕窗口打开买家网址验证。
  3. 买家端：下次打开工具时顶部出现「工具已更新 v新版本」提示条，点「立即刷新」自选时机升级；若本次带了新预设模板，刷新后预设模板库自动替换为新模板（自定义模板保留）。
手动部署（备用，一般用不到）

情况 A · 自己电脑双击用：把生成的文件（或 ZIP 解压出来的 index.html、version.js 等）覆盖到工具文件夹，注意备份旧文件。

情况 B · Cloudflare Pages 在线用：登录 dash.cloudflare.com → Workers 和 Pages → 你的项目 → Deployments → Create deployment → Direct Upload，把 ZIP 解压出的 index.html、version.js、update_log.js 等拖进上传区（根目录）→ Deploy site。或者：Pages 连了 Git 的话，把文件覆盖进仓库提交推送即可。

回退：重新用本工具发布一次旧口令即可；每次发布前状态栏都显示当前哈希，可对照确认。

本工具纯本地运行：除发布配置（你主动勾选记住）与发布历史外，不存储任何数据、不上传任何文件。
